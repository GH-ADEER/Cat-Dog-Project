# Cats vs Dogs Classification 🐱🐶

A Deep Learning project that uses a **Convolutional Neural Network (CNN)** to classify images as cats or dogs.

## Technologies

* Python
* TensorFlow & Keras
* NumPy
* Pandas
* Matplotlib
* Scikit-learn

## Model

The CNN uses **Conv2D, MaxPooling, Flatten, and Dense layers** for image classification.
